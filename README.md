# Talha Alam — AI Hardware Portfolio

The portfolio of Talha Alam, an electronics engineer working across digital VLSI, low-precision AI accelerators, FPGA systems, and open RTL-to-GDSII implementation.

The current site is a resume-led “silicon lab notebook”: AccelClosure and Gemmini lead the work list, followed by mixed-precision, Transformer, CNN, and FPGA systems. Case notes keep implementation scope and PPA evidence explicit.

## Run locally

```bash
npm install
npm run dev
```

## Verify a build

```bash
npm run lint
npm run build
```

GitHub Actions builds `dist/` and deploys it to GitHub Pages whenever `main` changes. Enable **Settings → Pages → GitHub Actions** once in the repository settings.
